# EPIC
A framework for lifelong reinforcement learning with PAC-Bayes generalization guarantees.

This repository contains the implementation of **EPIC**, which is described in our paper:  

📄 **[Statistical Guarantees for Lifelong Reinforcement Learning using PAC-Bayes Theory](https://zzh237.github.io/EPIC/)**  

We develop an EPIC-based lifelong reinforcement learning framework that enables adaptive policy updates and efficient knowledge transfer across tasks while ensuring statistical generalization guarantees.
